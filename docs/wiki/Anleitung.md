# Schritt-für-Schritt-Anleitung

1. **Installieren:** `SKILL.md` nach `~/.claude/skills/testaccount/SKILL.md` kopieren und die Basisadresse anpassen.
2. **Umgebung klären:** lokal/Staging oder live?
3. **Adresse wählen** und in die Konten-Liste eintragen.
4. **Konto anlegen:** lokal/Staging legt der Agent an; live legst du es selbst an.
5. **Mail suchen:** `to:name+tag@gmail.com` im Postfach.
6. **Prüfen:** Absender, Betreff, Design, Impressum, Links, Code.
7. **Abschließen:** Ergebnis berichten, Konto in der Liste als erledigt markieren.

## Beispiel

> „Teste die Registrierung auf `localhost:8080` mit einem neuen Testkonto."
> Der Agent wählt `name+app-3@gmail.com`, legt das Konto lokal an, liest die Bestätigungsmail und meldet das Ergebnis.
